# 首页分层素材

v0.6.8，基于原图 `assets/illustrations-portrait/song-yuan-er.png`，原图未覆盖。画布为 941×1672。

- `background.png`：内置 **image_gen** 编辑生成的补全底图，移除垂柳，保留粗枝、建筑、人物和构图。
- `willow-matte.png`：内置 **image_gen** 分离并清理的白底柳枝。真实 alpha 请求曾返回 RGB 棋盘格，该结果未打包；最终使用纯白底素材，由 Metal / WebGL 去白底并输出透明像素。
- `prompts.json`：生成底图、提取柳枝及清理白底的完整提示词。使用内置工具模式，没有使用 API/CLI 回退。
- `manifest.json`：源图与选定素材的大小及 SHA-256。

运行时的背景、原图下部、柳枝和细雨为独立图层；长短叶簇共享纹理，以连续根梢权重弯曲，避免切断交叠细枝。底图不变形，原图下半部覆盖保留道路与人物细节。静态模式直接使用原始封面。

本次是保留构图的图像分层编辑，生成的柳枝轮廓和疏密会有变化，不能视为无损抠图。资源约 3.6 MiB；PNG 受 `.gitignore` 排除，另行本地备份。iOS 打包脚本复制原始 PNG 字节并校验摘要，缺少一层时拒绝替换已有完整内容；两层都未提供时 App 使用原图。

# 逐首插画补全

本轮范围：保留原有 20 幅专属插画，按 `plan.json` 为另外 297 首各生成一张独立插画。原图放在 `assets/poem-art/<稳定诗篇ID>.png`。

2026-09-26 完成：297 / 297 张新增原图已生成、视觉检查并接入网页与原生资源；现有 317 首均有独立插画，无共用背景回退。原有 20 张图片及对应关系保持不变。

## 生成与检查

- 使用内置 imagegen；每首单独调用，未使用 CLI/API 批处理、拼图裁切或通用图冒充专属图。
- `plan.json` 保留逐首诗文参考、构图与风格提示词；`receipts-*.json` 保留输出来源、目标路径、视觉检查及必要的修订记录。
- 风格为暖色宣纸、淡彩水墨竖幅。画面按诗意绘制，中央与下方留出阅读空间；正文由客户端排版，图片中不添加诗文。
- `audit.json` 是最近一次文件审计的结果，包含尺寸、SHA256、检查记录和未完成清单。它反映已检查的原图数量；客户端数量以重建后的 `data/reader/build-report.json` 为准。

## 接入与验收

```sh
python3 scripts/audit_illustrations.py
python3 scripts/build_reader.py
npm test
python3 scripts/prepare_ios.py
```

全部补齐后运行 `python3 scripts/audit_illustrations.py --require-complete`。该命令要求 297 张原图全部存在、竖幅尺寸有效、文件内容无重复且均有视觉检查记录。

构建按「现有编辑配置 → 本轮逐首插画 → 旧视觉策划」选图。网页使用 940px WebP 大图和 240px 缩略图；iOS 使用同一份内容转出的本地 JPEG。图片尚未完成时才使用主题回退，且不会计入专属插画数量。精选状态独立于是否有插画，不会因为补图而把全库标成精选。

本轮不增加插画动画。生成图已作视觉检查，但不等同于历史服饰、建筑、器物的学术考证。

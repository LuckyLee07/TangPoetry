# 逐首插画与构图刷新

插画版本：v0.3.2，更新日期：2026-09-26；v0.3.3 仅调整排版，沿用本轮插画。

v0.3 按 `plan.json` 为原有 20 首之外的 297 首各生成一张独立插画，原图在 `assets/poem-art/<稳定诗篇ID>.png`。该轮 297 / 297 张已完成生成、视觉检查并接入网页与原生资源，形成 317 首均有专属插画的诗库。

v0.3.2 将旧图中的 7 张重新生成为下方有充足正文留白的 v2 全页图，取消此前独立画窗的呈现方式。当前 317 幅诗页由 13 张继续使用的旧图、297 张补图和 7 张 v2 刷新图组成。原有 20 张源文件全部保留，7 首当前图片映射已改用 v2；本轮 7 张审计、全库数据校验及原生资源打包已通过。

## 生成与检查

- 使用内置 imagegen；每首单独调用，未使用 CLI/API 批处理、拼图裁切或通用图冒充专属图。
- 风格为暖色宣纸、淡彩水墨竖幅。画面按诗意绘制，上方保留场景，中央与下方留出阅读空间；正文由客户端排版，图片中不添加诗文。
- 297 张补图的 `plan.json` 保留逐首诗文参考、构图与风格提示词；`receipts-*.json` 保留输出来源、目标路径、视觉检查及必要修订。
- `audit.json` 只审计原 297 张补图，包含尺寸、SHA256、检查记录和未完成清单。它不覆盖本轮 7 张 v2 图；客户端实际接入数量以重建后的 `data/reader/build-report.json` 为准。

## v0.3.2 的 7 张刷新图

范围为《鹿柴》《春晓》《江雪》《送元二使安西》（归档题名《渭城曲》）和《感遇其二》《感遇其三》《感遇其四》。它们的旧构图曾通过顶部画窗避让文字，本轮已逐张重新生成，不再依赖窗口裁切。

- v2 原图：`assets/poem-art-refresh/`。
- 提示词、生成来源、输出路径和视觉接受记录：`refresh-a.json`、`refresh-b.json`。
- 独立文件审计：`refresh-audit.json`，记录 7 张图片的尺寸、SHA256、路径唯一性和接受状态，7 / 7 通过。
- 接入方式：`data/editorial.json` 指向 v2 图，删除这 7 首的画窗与裁切配置，统一采用全页插画。旧源文件仍保留用于归档；它们不再作为这 7 首的当前诗页。

## 接入与验收

```sh
python3 scripts/audit_illustrations.py --require-complete
python3 scripts/build_reader.py
npm test
python3 scripts/prepare_ios.py
```

第一条命令只要求原 297 张补图全部存在、竖幅尺寸有效、文件内容无重复且均有视觉检查记录。7 张 v2 图使用独立的 `refresh-audit.json` 验收，不把原 297 张审计通过视为刷新图也已通过。

构建按「当前编辑配置 → 297 首补图计划 → 旧视觉策划」选图。网页使用 940px WebP 大图和 240px 缩略图，每首各一份。iOS 使用同一份诗库转出的 634 份本地 JPEG 诗页资源，并独立保留旧封面图，共 635 份图片。图片尚未完成时才使用主题回退，且不会计入专属插画数量。精选状态独立于是否有插画，不会因为补图或刷新而把全库标成精选。

本轮 `npm test` 的 5 项测试和 317 首数据校验通过，原生打包得到 317 首诗文与 635 份图片，iPhone 17 / iOS 26.2 的 9 项 XCTest 通过。实际页面检查确认《鹿柴》新图已按全页呈现，插画覆盖上下安全区，且不再使用画窗；《竹里馆》的图片同样铺满，文字和工具仍在安全区域。详细记录见项目根目录的 `PROGRESS.md`。

诗页正文直接利用图片留白，不叠加正文底色或渐变。iOS 图片覆盖上下安全区，正文和工具仍位于安全阅读区域；v0.3.3 在 v0.3.2 基础上将正文再上移 20pt、简注下移 15pt（网页使用同数值 px），极小屏保留最小起点。当前排版与弹层说明见项目根目录 `README.md`。

本轮不增加插画动画。视觉检查不等同于对历史服饰、建筑、器物的学术考证。

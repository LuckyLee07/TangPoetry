整理日期：2026-09-28。当前 **300 首**，已整理来源全文及逐首收录理由；尚未导入 App。按用户最新意见，以**脍炙人口、值得熟读**为优先，不要求主题均衡，不设作者配额。

此前推荐的 **93 首全部保留**，其余 **207 首**本轮替换了 **20 首**，补入《夜宿山寺》《上李邕》《南陵别儿童入京》《三五七言（秋风词）》《劝酒》《白鹿洞二首·其一》等。组诗按单首计数，长诗保留来源全文。当前涉及 **75 个来源作者署名**。

300 是规模目标，不是必须凑足的整数。这是一份编辑候选稿，熟悉程度属于编辑判断，没有为全部作品测量传播热度，也不宣称每首都是大众耳熟能详的名篇。后续可继续替换或缩减。

## 选诗原则

1. **熟悉的佳作优先。** 优先补齐广为传诵的作品；名句可作为查找线索，再确认全篇身份与正文。
2. **不按主题凑篇目。** 山水、送别、咏史等题材自然形成；不为了覆盖某一题材而降低入选标准，也不要求作者数量平均。
3. **短诗、长诗都可入选。** 长度与后续插画是否好做不决定文学取舍。目录按作者归组，便于查找，不表示排名。
4. **不重复前两卷。** 同诗异题、异署名和已存异文都纳入比对；组诗只选明确的单首。
5. **数量服从质量。** 保留约 300 首的扩展目标，允许后续淘汰和替换；不将生僻本身视为价值。

《诗境浅说》和马茂元《唐诗选》的参考作用，保留在诗作质量的判断上，不再用于设置主题或流派配额。《诗境浅说》参考[商务印书馆书介](https://www.cp.com.cn/book/b8a68123-9.html)对声调、意义、句法、字法与诗境的介绍；马茂元《唐诗选》参考陈尚君[《两种唐诗选》](https://dzb.whb.cn/images/2018-04/23/DS3/DS3B0423.pdf)所述的选本思路。

未对照两书的完整目录逐篇核实，因此书目收录关系均标为 `not-verified`。逐首理由是独立编辑短评，不是两书原评或网站赏析摘录。研究范围以已有 1,073 条候选记录为起点，本轮再补入 15 条原始来源；不声称对《全唐诗》做了穷尽排名。

历史选目与替换记录保存在 `sources/selection-before-popularity-review.json` 和 `sources/popularity-revision.json`。历史记录中的主题字段只用于追溯，当前选目已移除主题分组。被替换的诗文仍在上游研究库中。

## 文本与数据边界

主要来源承接[既有研究库](../tang-yizhu/README.md)，补充来源使用固定提交 `b8594f81a89752241442f2ce267d6f66f96704ee` 的开放《全唐诗》转录。每首保留原记录 ID、文件位置、来源链接及原始全文。底本数据许可见 [CHINESE_POETRY_LICENSE.txt](../tang-yizhu/sources/CHINESE_POETRY_LICENSE.txt)。未复制现代注释、赏析、插画或音频。

已处理《马诗》“山／沙”、《遗爱寺》“日／石”、送李判官诗“今陵／金陵”、《羌村》“块／愧”、《流莺》缺末联、玄都观看花诗题名纪年及《狂夫》首句误断标点。依据和原始读法均保留，详见 [REVIEW.md](REVIEW.md)。

仍需逐首定本，尤其《秦妇吟》的罕见字与长篇标点、若干异文、跨唐五代作者的单篇系年。句式分类只是自动初分，未完成平仄与用韵审校。所有记录保持 `publicationReady: false`。

- `id` 为稳定诗作身份；`order` 是本轮序号。作者归组后目录序号不连续，程序不要用行号代替身份。
- `paragraphs` / `text` / `sentences` 是本轮读法；`sourceReading` 保留未动过的来源读法、繁体及哈希。
- `author` 保留来源署名；`authorDisplay` 用于展示，例如来源“太宗皇帝”对应“李世民（唐太宗）”。
- `selection` 记录收录理由、原 93 首承接关系和待核书目归属；不再保存主题归类。
- `group`、`aliases`、`witnesses`、`variants`、`sourceAnnotations` 保留来源身份与异文，不将单首冒充全组。
- `editorialDecisions` 记录已采用的校订，`editorialNotes` 记录继续待核的事项。
- 改过正文的记录暂不生成未经核验的繁体定本；原始繁体仍在 `sourceReading`。
- 译文、词注、赏析、拼音、地点、系年等扩展内容未新增；插画与朗读未制作。

## 离线重建

使用 Python 3.10+ 及项目已有的 `opencc-python-reimplemented`：

```bash
python3 scripts/build_tang_third_volume.py
python3 tests/tang_third_volume_test.py -v
```

只依赖项目内数据，不联网、不读取临时文件。编辑入口为 `selection.json` 与 `sources/`，重建会验证原 93 首身份和正文重复，生成目录、全文、替换记录、数据与审计报告。发现重复时停止，不自动补位或凑数。

生成过程不写 App、iOS 工程、插图、音频和前两卷数据。
